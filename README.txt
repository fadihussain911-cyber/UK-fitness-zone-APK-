UK Fitness Zone - Gym Manager App

Install karne ka tareeqa:
1. Is folder ki saari files (zip khol kar) Netlify Drop (app.netlify.com/drop) ya GitHub Pages par upload karein.
2. Jo https link mile, usay phone ke Chrome mein kholein.
3. Menu se "Install app" ya "Add to Home Screen" dabayein.
4. Pehli baar internet chahiye, uske baad app offline chalti hai.

Zaroori: Settings mein Plans ki asli fees set karein. Hafte mein ek baar Settings se Backup download karein.
